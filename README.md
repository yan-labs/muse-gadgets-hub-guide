# Muse Gadgets Hub

A community directory for Muse AI agent projects, device skills, and board guides.

[Visit Muse Gadgets Hub](https://musegadgetshub.com/)

## Disclosure and purpose

This repository is the official public directory for Muse Gadgets Hub. The site is a free, unofficial English directory linking to community projects, device skills, and board guides for Meta's Muse AI agent and Muse Gadget SDK. It is not an independent review. Application source is not published here. A public GitHub listing here does not guarantee search-engine indexing, ranking, or backlink value.

## What it does

Use the directory to discover projects and follow links to their original sources. It does not sell hardware, issue SDK tokens, or verify device performance. Muse here is Meta's personal AI agent, not the Muse EEG headband or ESP MUSE boards; see [Which Muse?](https://musegadgetshub.com/which-muse).

## How to get started and key pages

| Page | What you can do |
| --- | --- |
| [Getting started](https://musegadgetshub.com/getting-started) | Check the official hardware list, then choose a listed ESP32 board, Raspberry Pi (3B+, 4, 5, or Zero 2 W), or another Linux computer with Bluetooth LE. Get a personal SDK token and review the Gadget SDK Terms on the official site under Account > SDK tokens. Every gadget needs a token to pair, including personal builds; this directory cannot issue one. Follow the official flash/install path, pair in the Muse app, then customize and share. |
| [ESP32 vs Linux](https://musegadgetshub.com/compare/esp32-vs-linux) | Compare setup, permissions, and capabilities before choosing hardware. |
| [Projects](https://musegadgetshub.com/projects) | Browse community projects and their source links. |
| [Skills](https://musegadgetshub.com/skills) | Explore device skills. |
| [Boards](https://musegadgetshub.com/boards) | Browse board guides. |

## Limits and disclaimer

Capabilities depend on hardware and account permissions. The directory links to sources rather than testing devices. If flashing ESP32, the official firmware requires ESP-IDF 6.0.1.
